# Media placeholders

This folder contains portfolio mockups made from UNIBOX demo screenshots. The original desktop background was replaced with a clean studio backdrop. The personal email on the profile screen was replaced with "Demo account".

The sequence is:

1. `01-explore-boxes.png` — demo home and Box discovery.
2. `02-box-details.png` — fixed ticket and proposed Box process.
3. `03-founder-voting.png` — short founder pitch and simulated voting.
4. `04-demo-updates.png` — fictional demo activity notifications.
5. `05-demo-profile.png` — fictional balance and activity, with the personal email removed.

All amounts, member counts, balances, votes, startups, and transactions shown are fictional UI data. These mockups are visual demonstrations, not evidence of live funding or financial activity.

Future additions can include approved team photos or updated screens. Before adding any file, remove private information, account details, API keys, personal contact information, and real financial or legal documents. Use only images the team has permission to publish.
